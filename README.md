# Weather App

A simple and elegant web application that provides real-time weather information for any city in the world.

## Features

-   **Current Weather:** Get the current temperature, weather description, and an icon representing the conditions.
-   **City Search:** Easily search for any city to get its weather details.
-   **Responsive Design:** The application is fully responsive and works seamlessly on desktops, tablets, and mobile devices.

## How to Use

1.  Open the `index.html` file in your web browser.
2.  Enter the name of a city in the input field.
3.  Click the "Get Weather" button.
4.  The weather information for the specified city will be displayed.

## Technologies Used

-   **HTML:** For the structure of the web page.
-   **CSS:** For styling the application and making it responsive.
-   **JavaScript:** For fetching data from the OpenWeatherMap API and dynamically updating the page.
-   **OpenWeatherMap API:** To retrieve weather data.
